# Security policy

Please report vulnerabilities privately to the maintainers before public disclosure. On GitHub, use the repository's **Report a vulnerability** link in the Security tab (private vulnerability reporting). If that option is unavailable, contact the repository owner through their GitHub profile and request a private disclosure channel. Do not post exploit details, secrets, or private source in a public issue.

Maintainers should enable private vulnerability reporting in the repository's **Settings → Code security and analysis** so researchers can submit reports privately.

Patchlens treats repository content and diff text as untrusted input. The analyzer does not execute repository code. Security rules are heuristic and do not replace review or dedicated scanners.
